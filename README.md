## ECU Diagnóstico Automotriz
Proyecto de diagnóstico para **Audi TT Mk1 (8N)**

### 🚗 Descripción
DCTT es una herramienta pensada para leer códigos de falla, interpretar averías y facilitar el diagnóstico de la ECU del Audi TT Mk1 8N.

### 📁 Archivos incluidos
- `dctt.cpp` → Código fuente principal del programa
- `dctt.ico` → Ícono de la aplicación
- `averias.csv` → Base de datos de averías
- `INSTALAR.bat` → Script de instalación
- `LEEME‑PRIMERO.txt` → Instrucciones prioritarias (lee primero)
- `LEEME.txt` → Información general del proyecto
- `dctt‑fuente.zip` → Copia comprimida del código fuente

### ⚙️ Instalación
1. Abre `LEEME‑PRIMERO.txt` y lee las indicaciones
2. Ejecuta `INSTALAR.bat` para iniciar la instalación
3. Consulta `LEEME.txt` para más detalles de funcionamiento
